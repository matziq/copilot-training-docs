Windows editions and upgrades

Know which edition has which feature before you troubleshoot it.

CompTIA likes edition questions because they look like troubleshooting but are really feature-boundary questions. If the feature is not licensed in that edition, no amount of driver repair or service restarting will make it appear.

Feature Home Pro Pro for Workstations Enterprise
Domain join No Azure AD or Active Directory domain join for classic business domains Yes Yes Yes, with enterprise management
BitLocker Device encryption only on supported systems; no full BitLocker management UI Yes Yes Yes, with enterprise recovery and policy control
Group Policy Editor gpedit.msc No local editor Yes Yes Yes
Remote Desktop host No host; can connect as a client Yes Yes Yes
Hyper-V No Yes, if CPU virtualization is enabled Yes Yes
Maximum RAM 128 GB on 64-bit Windows 10/11 2 TB on 64-bit Windows 10/11 6 TB on 64-bit Windows 10/11 6 TB on 64-bit Windows 10/11

Classic trap: RDP host vs client

Every Windows edition can run the Remote Desktop client and connect to another computer. Windows Home cannot be the Remote Desktop host that accepts inbound RDP sessions.

If a home user asks why Remote Desktop cannot be enabled for incoming connections, the answer is edition limitation, not firewall, driver, or service corruption.

Classic trap: Home cannot join a domain

Windows Home is for consumer workgroups. If a company needs Active Directory domain join, Group Policy, BitLocker management, or RDP host capability, upgrade to Pro or higher.

Upgrade paths

  • Home → Pro is the common edition upgrade path.
  • Pro → Enterprise normally requires enterprise licensing or activation.
  • Windows 10 → Windows 11 can be an in-place upgrade only if hardware requirements are met.
  • 32-bit → 64-bit requires a clean install; it is not an in-place architecture upgrade.

In-place vs clean install

  • In-place upgrade preserves installed applications, user files, and most settings.
  • Repair install refreshes Windows system files while trying to preserve apps and data.
  • Clean install wipes the target Windows installation and requires reinstalling apps.
  • Back up user files, license keys, browser data, and application settings before either path.

Feature updates install a new Windows build and can change the operating system’s feature set. Quality updates are cumulative security, reliability, and bug-fix updates for the current build.

A 32-bit Windows installation can address only about 4 GB of RAM total. Hardware reservations usually make usable memory lower than exactly 4 GB. A 64-bit CPU and 64-bit Windows are required to use modern memory capacities.

Windows 11 requires a 64-bit CPU, UEFI firmware, Secure Boot capability, and TPM 2.0. If one of those is missing or disabled, the installation check fails before normal upgrade troubleshooting matters.

File systems and partitioning

Match the format to the operating system, device, and file-size requirement.

The file system determines maximum file size, metadata, permissions, journaling, and cross-platform compatibility. The exam often gives you a USB-drive scenario and asks why a copy fails.

File system Max file size Max volume size Journaling Permissions support Where it is used
NTFS Very large; practical Windows limits are far beyond normal desktop files Very large; commonly used for Windows system and data volumes Yes Yes, with ACLs, compression, EFS, quotas, and auditing Windows internal drives, business workstations, servers, BitLocker volumes
exFAT 16 EB class 128 PB class No No NTFS-style permissions Large flash drives and SD cards shared between Windows, macOS, cameras, and devices
FAT32 4 GB minus 1 byte 2 TB practical limit for many tools and devices No No Older USB drives, firmware update media, broad compatibility scenarios
ext3/ext4 ext3 commonly up to 2 TB; ext4 commonly up to 16 TiB per file ext3 commonly up to 32 TiB; ext4 supports much larger Linux volumes Yes Yes, with Linux ownership and mode bits Linux system and data partitions
APFS 8 EB class 8 EB class Metadata journaling and copy-on-write design Yes, with macOS permissions and encryption support Modern macOS, SSDs, Time Machine destinations on recent macOS versions
Memorize FAT32’s limit

FAT32 has a 4 GB single-file limit. If copying a large ISO, virtual disk, or video to a USB drive fails even though the drive has enough free space, the file system is usually FAT32.

The quick fix is to reformat the removable drive as exFAT for broad compatibility or NTFS for Windows features and permissions.

MBR

  • Legacy partitioning style.
  • Allows four primary partitions.
  • Can use an extended partition to contain logical drives.
  • Has a 2 TB disk-size limit for bootable/basic use.
  • Usually paired with BIOS or Legacy/CSM boot.

GPT

  • Modern partitioning style.
  • Supports 128 partitions in Windows without extended/logical workarounds.
  • Supports volumes over 2 TB.
  • Stores redundant partition-table data for resilience.
  • Requires UEFI firmware to boot Windows from the disk.

Primary partitions can host an operating system or data. Extended partitions are MBR containers used to create more than four usable volumes. Logical drives live inside an extended partition.

Basic disks are the normal Windows disk type and use primary partitions, extended partitions, or GPT partitions. Dynamic disks support software-based spanned, striped, mirrored, and RAID-5 style volumes, but they are less common on modern client systems.

A quick format creates a new file system structure and marks space as available; it does not thoroughly overwrite all user data. A full format checks the disk and, on modern Windows, writes zeros to the volume while preparing the file system. A true wipe or sanitize operation is still the better answer when the goal is secure data removal.

Boot methods and installation

Identify the boot source and the install type before changing firmware settings.

Boot problems are often firmware-order problems. Installation problems are often compatibility, driver, or backup-preparation problems.

Removable and local boot

  • USB flash drive is the most common modern install and recovery method.
  • Optical disc still appears in exam objectives for legacy DVD installation.
  • External or hot-swappable drive can boot diagnostics, recovery media, or portable OS tools.
  • Internal hard drive partition may contain recovery tools or a factory restore image.

Network and internet boot

  • PXE boots from the network card and loads deployment or recovery tools from a server.
  • Internet-based recovery downloads the recovery environment from the vendor or OS provider.
  • Network installs need DHCP, network connectivity, and a reachable deployment service.

Firmware settings

  • Boot order decides which device the system tries first.
  • UEFI replaces classic BIOS on modern systems.
  • Secure Boot validates bootloaders and blocks untrusted boot code.
  • Legacy/CSM mode is for older operating systems and MBR boot disks.
Switching Legacy/CSM to UEFI is not just a toggle

Windows installed in Legacy mode on an MBR disk may not boot after switching to UEFI. UEFI boot normally expects GPT partitioning and a UEFI boot entry.

Use the proper conversion path, such as mbr2gpt where supported, or perform a clean UEFI/GPT installation.

Installation or recovery choice What it is for What it preserves
Repair install Reinstall Windows system files over the existing installation Attempts to preserve apps, user data, and settings
Recovery partition Boot vendor or Windows recovery tools from a hidden local partition Depends on option selected; factory recovery may erase data
Refresh/reset Return Windows to a clean state from Windows Recovery Environment Keep my files preserves user files; Remove everything does not
Clean install Install a fresh operating system to a target volume Nothing on the target unless backed up or migrated first
Image deployment Apply a prepared corporate image to many computers Standardized apps and settings in the image; local data must be migrated
Pre-installation checklist
  • Verify application support for the target operating system and edition.
  • Verify driver support for storage, network, graphics, printers, scanners, and specialty hardware.
  • Back up user files, desktop data, browser favorites, profiles, and application settings.
  • Record licensing, activation, VPN settings, and line-of-business application requirements.
  • Download third-party storage or network drivers before starting if the installer may not include them.

Most-tested tool picks

For A+, the highest-yield tools are Device Manager for drivers, Event Viewer for logs, Disk Management for partitions and drive letters, Task Manager for live processes and startup apps, and Services for background service state.

Regedit has no friendly undo

Back up the registry, export the key, or create a restore point before making registry changes. A wrong registry edit can stop Windows, apps, services, or drivers from working.

Windows networking configuration

Separate identity, profile, addressing, sharing, and remote-access settings.

Workgroup vs domain

A workgroup is peer-to-peer. Each PC manages its own local users, local permissions, and local policies.

A domain is centrally managed by Active Directory. Joining a domain changes sign-in options, applies Group Policy, enables domain security groups, and allows centralized authentication.

Network profiles

Public is restrictive for untrusted networks. Discovery and inbound sharing are usually blocked.

Private is for trusted home or office networks where discovery and sharing may be allowed.

Domain is automatically used when the computer authenticates to a domain network.

Mapping a network drive connects a drive letter to a shared path. The command-line version is net use Z: \\server\share. Printer sharing follows the same basic idea: the printer is shared from one host or print server, and clients connect to that share.

A VPN creates an encrypted tunnel into a remote private network. Configure the VPN type, server name, authentication method, and credentials; then test DNS and routing, not just the connected icon.

Proxy settings define an intermediary for web traffic. Metered connections tell Windows to reduce background data use. An alternate IP configuration lets a device use a fallback static IPv4 address when DHCP is unavailable.

Configuration method Best use Example
GUI Single workstation changes and visible verification Settings → Network and Internet, or adapter properties from Control Panel.
netsh Legacy command-line network configuration and troubleshooting netsh interface ip show config displays adapter IP settings.
PowerShell Modern scripting and remote administration Get-NetIPConfiguration checks adapters; New-NetIPAddress configures static IP details.

macOS and Linux

Translate Windows thinking into Apple and Linux terms.

macOS essentials

  • Time Machine performs versioned backups to local or network destinations.
  • FileVault encrypts the macOS startup disk.
  • Disk Utility partitions, formats, repairs, and images disks.
  • Keychain stores passwords, certificates, and secure notes.
  • Spotlight searches files, apps, email, and metadata.
  • Mission Control manages windows, desktops, and full-screen spaces.
  • Gatekeeper helps block untrusted or unsigned software.
  • Force Quit closes a frozen application.

macOS install and user details

  • App Store installs are curated and update through Apple’s store workflow.
  • Third-party installs may use signed packages or disk images from trusted vendors.
  • .dmg is a mountable disk image.
  • .pkg is an installer package.
  • .app is an application bundle.
  • Remote Disc shares an optical drive from another Mac or PC in supported scenarios.
  • iCloud synchronizes Apple ID data, files, photos, keychain data, and device features.
  • Gestures use the trackpad or Magic Mouse for scrolling, zoom, desktop switching, and Mission Control.
Linux directory map

/ is the root of the file system. /home stores user profiles, /etc stores configuration, /var stores changing service data and logs, /tmp is temporary storage, /bin and /usr/bin store user commands, and /sbin stores system administration commands.

Linux package managers install and update software from repositories. Debian and Ubuntu use apt-get or apt. Red Hat-family distributions historically used yum; newer versions commonly use dnf.

Linux permissions use owner, group, and others. The numeric mode is octal: read is 4, write is 2, execute is 1, and the values are added for each class. 755 means owner rwx, group r-x, others r-x. 644 means owner rw-, group and others r--. 600 means only the owner can read and write.

The root account is the all-powerful administrator. sudo lets an authorized user run a specific command with elevated privileges while preserving accountability. Samba provides SMB/CIFS file and printer sharing so Linux can interoperate with Windows networks.

The night-before Operating Systems sheet

Compress the largest Core 2 domain into fast recall.

Edition recall

  • Home: consumer workgroups; no domain join, no gpedit.msc, no RDP host, no Hyper-V, limited BitLocker management.
  • Pro: domain join, BitLocker, gpedit.msc, RDP host, Hyper-V, stronger update control.
  • Pro for Workstations: Pro plus high-end hardware support, ReFS support, and workstation-class features.
  • Enterprise: Pro features plus enterprise deployment, policy, security, and update management.

Storage recall

  • FAT32 has a 4 GB single-file limit.
  • MBR: four primary partitions and 2 TB limit.
  • GPT: 128 Windows partitions, volumes over 2 TB, UEFI boot.
  • Quick format rebuilds metadata; full format checks and overwrites in modern Windows; wipe is for sanitization.

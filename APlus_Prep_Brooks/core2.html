CompTIA A+ Core 2

Core 2 (220-1102)

Core 2 is the other half of the A+ certification. Both exams must be passed to be certified, and Core 2 has its own passing mark of 700 on the 100–900 scale; Core 1 passes at 675. This page is the map of the four Core 2 domains, and if Core 2 is the exam being sat on September 4, this page plus the six Core 2 drills and the Core 2 diagnostic exam are where to start.

Which exam are you actually sitting?

The rest of this site is built for Core 1 (220-1101), the hardware, networking, mobile, virtualization, and troubleshooting half. If the September 4 booking is for Core 2, the study order flips: work this page and the c2- drills first, take practice-exam-4.html as the baseline, and treat the Core 1 guides as the follow-on. Stay calm: this is still A+, just a different map.

1.0 Operating Systems (28%)

Goal: pick the right operating system feature, tool, install choice, or filesystem.

Core 2 operating systems questions are not just about clicking around Windows. They ask which edition, installation method, filesystem, control panel, administrative tool, or shell command solves a specific support problem.

Edition trap

If the question says domain join, Group Policy Editor, full BitLocker management, or Remote Desktop host, Home is usually the wrong answer. If it says extreme workstation hardware, persistent memory, or server-grade workstation storage, think Pro for Workstations.

Upgrade paths, installs, and updates

  • An in-place upgrade keeps applications, user data, and settings when the existing operating system and edition support the upgrade path.
  • A clean install starts fresh and is best for badly corrupted systems, new drives, major edition changes, malware-damaged builds, or when you need a known-good baseline.
  • Upgrade paths usually move from an older supported Windows version to a newer one, or from a lower edition to a higher edition, not backward.
  • A feature update is a larger release that changes Windows capabilities and version level.
  • A quality update is a smaller cumulative security, reliability, and bug-fix update.
  • On the exam, feature update means bigger change; quality update means routine patching.
  • 32-bit Windows can address about 4 GB of RAM and runs 32-bit applications.
  • 64-bit Windows supports much more RAM and runs 64-bit applications plus most 32-bit applications.
  • Use 64-bit Windows for modern hardware unless an old 32-bit-only driver or application forces otherwise.

Boot methods and installation sources

USB

The common field method for installing Windows, running recovery media, or booting diagnostic utilities.

Optical

Older but still testable. Think DVD install media, legacy recovery discs, or vendor rescue media.

Network/PXE

Boots from a network deployment server, common in managed business imaging and mass deployment.

Internet-based

Downloads recovery components from the vendor or cloud when local recovery is missing or damaged.

External or hot-swappable drive

Useful for imaging, diagnostics, or replacing storage without opening some systems.

Internal hard drive partition

Recovery partition or local installer partition used to reset or restore the system.

  • Devices and Printers: printer properties, default printer, and device troubleshooting.
  • Programs and Features or Apps: uninstall, repair, and manage installed applications and Windows features.
  • Network and Sharing Center or Network & Internet: adapters, sharing, proxy, VPN, and connection properties.
  • Windows Defender Firewall: allowed apps, inbound/outbound rules, and active firewall profile.
  • System: computer name, domain/workgroup, activation, Remote Desktop, and advanced system settings.
  • Power Options: sleep, hibernate, lid behavior, and performance versus battery tradeoffs.
  • Credential Manager: saved Windows and web credentials.
  • Sync Center: offline files in business environments.
  • Time and Language: date, time zone, region, and keyboard settings.
  • Ease of Access or Accessibility: screen reader, magnifier, high contrast, captions, and input assistance.
  • Update & Security or Windows Update: patches, recovery, activation, and backup-related options.

Windows networking

  • A workgroup is peer-to-peer; each computer manages its own local users and permissions.
  • A domain is centrally managed with Active Directory, domain accounts, Group Policy, and centralized authentication.
  • Mapped drives assign a drive letter to a network share so users can access it like local storage.
  • Printer sharing lets other users print through a shared printer or print server, subject to permissions and drivers.
  • Metered connections reduce background data use and can delay some downloads on limited networks.
  • Proxy settings send web traffic through an intermediary server for filtering, logging, or access control.
  • Windows Firewall has domain, private, and public profiles; public is the most restrictive posture for untrusted networks.

macOS and Linux

macOS tools

  • Time Machine backs up and restores files or systems.
  • FileVault encrypts the startup disk.
  • Disk Utility partitions, changes file systems, verifies, and repairs disks.
  • Keychain stores passwords, certificates, and secure notes.
  • Spotlight searches files, apps, and metadata.
  • Mission Control shows spaces, desktops, and open windows.
  • Gatekeeper helps block untrusted or unsigned apps.

Linux command recognition

ls, cd, pwd, mv, cp, rm, chmod, chown, grep, ps, su/sudo, apt-get/yum, df, dd, cat, find, top, man, and ip.

Translate the verb: list, move, copy, remove, permissions, ownership, search, processes, privilege, packages, disk free, image/copy, display, locate, live process view, manual, and network addressing.

2.0 Security (28%)

Goal: apply the correct control and preserve data, access, and evidence.

Security is tied with operating systems for the largest Core 2 domain. Expect scenario questions: identify the control, apply least privilege, remove malware in order, and protect data correctly.

Physical security

  • Bollards stop vehicles from ramming entrances or protected areas.
  • An access control vestibule, also called a mantrap, lets one person through after authentication and prevents tailgating.
  • Badge readers authenticate possession of an issued credential.
  • Video surveillance records activity and deters misconduct.
  • Alarm systems alert on unauthorized entry or tampering.
  • Motion sensors detect movement in protected areas.
  • Door locks are basic physical access control.
  • Equipment locks secure laptops, docks, and devices to desks or racks.
  • Guards provide human monitoring, challenge, and response.
  • Fences define a perimeter and delay entry.
  • Lighting deters intruders and improves camera effectiveness.
  • Magnetometers detect metal weapons or objects at controlled entrances.

Logical security

  • The principle of least privilege means a user or process receives only the access needed to do the job, no more.
  • ACLs define who can access an object and what actions they can perform.
  • MFA combines factor categories: something you know, something you have, something you are, something you do, and somewhere you are.
  • Soft tokens are generated by software such as authenticator applications.
  • Hard tokens are physical devices such as smart cards, USB security keys, or hardware one-time-password tokens.
  • SMS codes are possession-based but weaker than app or hardware tokens because of SIM-swap and interception risks.
  • Authenticator applications generate or approve codes on a trusted device.
  • Email-based codes can verify account access but are weaker if the email account is already compromised.

Active Directory

  • A login script runs at user sign-in to map drives, set printers, or configure user environment settings.
  • A domain centralizes identity, authentication, and policy for managed computers and users.
  • Group Policy applies user and computer settings, security baselines, scripts, and update behavior.
  • Organizational units group users, computers, or resources so policies and administration can be delegated cleanly.
  • A home folder is a user-specific network storage location.
  • Folder redirection points known folders, such as Documents, to network or managed locations.
  • Security groups assign access based on membership instead of one user at a time.

Wireless security

  • WPA3 is newer and stronger than WPA2, especially for password-authenticated networks.
  • WPA2 remains common and is acceptable when configured with AES.
  • AES is the strong encryption choice; TKIP is older and should be avoided when possible.
  • RADIUS provides centralized AAA for network access, commonly with 802.1X.
  • TACACS+ is another AAA protocol often associated with network device administration.
  • Kerberos is a ticket-based authentication protocol used heavily in Active Directory domains.
  • 802.1X is port-based network access control for wired or wireless networks, often backed by RADIUS.

Seven-step CompTIA malware removal process

  1. Investigate and verify malware symptoms.
  2. Quarantine the infected system.
  3. Disable System Restore in Windows.
  4. Remediate infected systems: update anti-malware software, then scan and remove.
  5. Schedule scans and run updates.
  6. Enable System Restore and create a restore point in Windows.
  7. Educate the end user.
Order matters

Do not jump straight to removal. CompTIA wants quarantine before remediation, System Restore disabled before cleaning, and user education after the system is healthy.

NTFS, encryption, and destruction

  • NTFS permissions apply locally and over the network; share permissions apply only when accessing through the share.
  • When NTFS and share permissions both apply over a network, the most restrictive effective permission wins.
  • UAC prompts for elevation so standard tasks do not run with administrative rights by default.
  • BitLocker encrypts entire internal Windows volumes.
  • BitLocker To Go encrypts removable drives.
  • EFS encrypts individual files or folders for a user within NTFS.
  • Shredding destroys paper or media physically.
  • Drilling destroys platters or chips by physical damage.
  • Degaussing uses a magnetic field to destroy data on magnetic media, but not SSDs.
  • Incinerating destroys media by burning.
  • A low-level format is deeper sanitization terminology; a standard format is not enough for secure disposal.
  • A certificate of destruction proves a disposal vendor destroyed assets.
  • Outsourcing to a third party requires trust, documentation, and chain-of-custody control.

3.0 Software Troubleshooting (23%)

Goal: choose the most likely cause and least destructive fix.

Software troubleshooting questions usually describe symptoms. Your job is to pick the most likely cause and the least destructive fix that fits the evidence.

Available remedies

  • Reboot to clear temporary state and complete pending changes.
  • Restart services when one service is hung but the OS is otherwise stable.
  • Uninstall, reinstall, or update applications when the problem follows one app.
  • Add resources when CPU, RAM, disk, or storage limits are proven.
  • Verify requirements before blaming Windows for an unsupported application.
  • Use System File Checker for protected Windows file corruption.
  • Repair Windows when system components are damaged but data should remain.
  • Restore to a known-good restore point when the problem started after a change.
  • Reimage when the system must return to a clean approved baseline.
  • Roll back updates when a new patch or driver caused the symptom.
  • Rebuild Windows profiles when one user profile is corrupt and other users work normally.

PC security symptoms

  • Unable to access the network can be malware, firewall change, proxy tampering, or DNS hijack.
  • Desktop alerts can be real security software or fake scareware; verify the source.
  • False antivirus alerts are classic rogue security software.
  • Altered system files point to malware or unauthorized changes.
  • Unwanted notifications often come from browser permission abuse or adware.
  • OS update failures can be malware, damaged components, or insufficient space.
  • Browser redirection suggests DNS, proxy, extension, or malware compromise.
  • Certificate warnings can mean wrong time, captive portal, SSL inspection, spoofing, or on-path attack.

Mobile OS and application symptoms

  • Application fails to launch: update the app, check OS version, clear cache, reinstall, or verify service status.
  • Application fails to close or crashes: force close, update, reboot, reinstall, or check storage.
  • Application fails to update: check account, storage, network, OS support, and app store status.
  • Slow to respond: close apps, reboot, free storage, update OS/apps, or check battery health.
  • OS fails to update: verify compatibility, charge level, storage, Wi-Fi, and vendor availability.
  • Battery life issues: check battery usage, brightness, radios, background apps, and battery health.
  • Randomly reboots: suspect OS bugs, overheating, battery failure, bad app, or hardware issue.
  • Connectivity issues: toggle airplane mode, verify Wi-Fi/cellular/Bluetooth settings, forget and reconnect, or reset network settings.
  • Screen does not autorotate: check rotation lock, sensors, app support, and reboot.

Mobile security symptoms

  • High network traffic can indicate sync loops, compromise, tethering, or rogue applications.
  • Data-usage limit notification may reveal runaway apps or unauthorized tethering.
  • Limited internet connectivity can be captive portal, DNS, VPN, malware, or signal problem.
  • No internet connectivity can be radio disabled, account issue, bad APN, Wi-Fi problem, or MDM restriction.
  • Fake security warnings are scareware or malicious web notifications.
  • Unexpected application behavior suggests malicious, outdated, or corrupted apps.
  • Leaked personal files or data can indicate cloud sync exposure, weak permissions, lost device, or compromised account.

4.0 Operational Procedures (21%)

Goal: behave like a careful technician, not just a clever troubleshooter.

Operational procedures are easy to underestimate. They test how a professional technician documents work, protects people, handles risk, communicates, and follows rules.

Documentation

Ticketing systems
  • User information belongs in the ticket: name, contact, department, location, and availability.
  • Device information belongs in the ticket: asset tag, serial number, hostname, OS, application, and warranty status.
  • Description of problem should capture what changed, what failed, when it started, and how often it happens.
  • Categories route the work to the right queue and support reporting.
  • Severity describes impact and urgency.
  • Escalation levels show when and where to hand off.
  • Clear and concise written communication keeps the next technician from guessing.
  • Problem description, progress notes, and problem resolution must be written so someone else can follow the timeline.
Asset management
  • Inventory lists track what exists.
  • A database system tracks ownership, status, lifecycle, and history.
  • Asset tags and IDs tie the physical device to records.
  • Procurement lifecycle covers request, purchase, receive, deploy, maintain, and retire.
  • Warranty and licensing records prevent unsupported or illegal use.
  • Assigned users show who is responsible for the asset and where it should be.
Documents to recognize
  • Acceptable use policy defines permitted and prohibited technology behavior.
  • Network topology diagram shows device and connection layout.
  • Regulatory compliance requirements document legal or industry obligations.
  • Splash screens can present notices before system or network use.
  • Incident reports document security, safety, or operational incidents.
  • Standard operating procedures define repeatable approved processes.
  • New-user setup checklist standardizes onboarding.
  • End-user termination checklist standardizes account, device, and access removal.
  • Knowledge base and articles preserve fixes for repeated issues.

Change management

  1. Rollback plan.
  2. Sandbox testing.
  3. Scope of the change.
  4. Risk analysis.
  5. Change board approvals.
  6. End-user acceptance.
Change-control mindset

Before touching production, know how to undo the change, prove it in a sandbox, define what is affected, analyze risk, get approval, and confirm users accept the result.

Backup and recovery

Backup typeWhat it copiesRestore requires
FullAll selected data every time.Only the latest full backup.
IncrementalData changed since the last backup of any type.Last full backup plus every incremental since then.
DifferentialData changed since the last full backup.Last full backup plus the latest differential.
SyntheticA constructed full backup made from earlier full and incremental data, usually on the backup system.The synthetic full set presented as a full restore point.
  • The 3-2-1 rule means three copies of data, on two different media types, with one copy off-site.
  • Grandfather-father-son rotation uses monthly, weekly, and daily backups.
  • On-site backups restore quickly but can be lost in the same disaster as the system.
  • Off-site backups protect against site disasters but may restore more slowly.
  • Backup testing proves the data can actually be restored; untested backups are guesses.

Safety

  • ESD straps and mats reduce electrostatic discharge risk.
  • Equipment grounding protects people and components.
  • Proper power handling means unplugging equipment, using correct power ratings, and avoiding overloaded circuits.
  • Proper component handling and storage means edges, bags, labels, and no stacking abuse.
  • Antistatic bags protect components outside the computer.
  • Compliance with government regulations covers disposal, safety, privacy, and workplace rules.
  • Personal safety includes disconnecting power before repairing, correct lifting technique, electrical fire safety, safety goggles, and an air filtration mask when needed.

Environmental impacts

  • MSDS/SDS handling and disposal instructions apply to chemicals, toner, batteries, and hazardous materials.
  • Temperature, humidity, and ventilation affect system reliability and electrostatic risk.
  • Power surges, brownouts, and blackouts can damage equipment or corrupt data.
  • Battery backup gives systems time to shut down or ride through short outages.
  • Surge suppressors protect against voltage spikes but are not a replacement for backups or UPS planning.

Prohibited content and licensing

  • For prohibited content or security incidents, follow incident response policy and preserve chain of custody.
  • First response means identify the issue, report through proper channels, and preserve data and the device.
  • Documentation should show who handled evidence, when, where it was stored, and what actions were taken.
  • Licenses must be valid and non-expired.
  • Personal licenses are not the same as enterprise licenses.
  • Open source licenses still have rules; commercial licenses usually define seats, devices, users, and support rights.
  • PII, PCI, GDPR, and PHI are data-protection categories that require careful handling, minimum access, and proper reporting.

Communication and professionalism

  • Use clear, concise language.
  • Avoid jargon and slang unless the audience understands it.
  • Maintain a positive attitude even when the fix is slow.
  • Use active listening: restate, clarify, and confirm.
  • Show cultural sensitivity and do not make assumptions.
  • Be punctual and communicate delays early.
  • Avoid distractions while working with the user.
  • Dealing with difficult customers means staying calm, not arguing, and focusing on the next step.
  • Set and meet expectations for time, scope, and follow-up.
  • Handle confidential material appropriately and discuss it only with authorized people.

Script risks include unintentionally changing system settings, browser or system crashes, and mishandling of resources such as files, memory, credentials, or network calls. Read scripts before running them, test in a safe place, and run with the least privilege that works.

Remote access technologies

  • RDP provides graphical Windows remote access; secure it with VPN, MFA, Network Level Authentication, and restricted exposure.
  • VPN creates an encrypted tunnel into a private network; secure it with strong authentication and current clients.
  • VNC provides graphical remote control; secure it carefully because weak VNC exposure is risky.
  • SSH provides encrypted command-line access, common on Linux and network devices; use keys and disable weak passwords when possible.
  • RMM tools provide managed monitoring and remote support; protect the console because it has broad control.
  • MSRA, Microsoft Remote Assistance, lets a helper assist a user with consent.
  • Third-party tools are useful but require licensing, approval, MFA, logging, and vendor trust review.

The night-before Core 2 sheet

Goal: pure recall without hesitation.

Use this section for pure recall. Cover the answer, say it, then check it. If you cannot say it quickly, drill it again.

Malware removal order

  1. Investigate and verify malware symptoms.
  2. Quarantine the infected system.
  3. Disable System Restore in Windows.
  4. Remediate infected systems: update anti-malware software, then scan and remove.
  5. Schedule scans and run updates.
  6. Enable System Restore and create a restore point in Windows.
  7. Educate the end user.

Change management order

  1. Rollback plan.
  2. Sandbox testing.
  3. Scope of the change.
  4. Risk analysis.
  5. Change board approvals.
  6. End-user acceptance.

Backup types

Full copies all selected data. Incremental copies changes since any last backup and restores with full plus all incrementals. Differential copies changes since last full and restores with full plus latest differential. Synthetic builds a new full from prior backup data.

NTFS vs share

NTFS applies locally and over the network. Share applies over the network only. Across the network, combine NTFS and share permissions and the most restrictive wins.

MFA factors

Something you know, something you have, something you are, something you do, and somewhere you are.

Wireless security

Prefer WPA3. If WPA2 is used, prefer AES. Avoid TKIP unless legacy compatibility forces it.

Filesystem traps

FAT32 has a 4 GB single-file limit. NTFS is the Windows security default. exFAT is useful for cross-platform removable storage with large files.

Partition traps

MBR: 4 primary partitions and 2 TB limit. GPT: commonly 128 partitions, supports disks over 2 TB, and needs UEFI to boot Windows.

Ten most-tested commands

ipconfig /all · ipconfig /flushdns · ping · tracert · pathping · nslookup · net use · sfc /scannow · dism · gpupdate /force.

If a question asks for a route, use tracert. If it asks for route plus packet loss, use pathping. If Windows system files are damaged, use sfc /scannow; if the component store/image is damaged, use dism.

Access cue

Local access only points to NTFS. Network share access points to both NTFS and share rules. Domain access points to groups and policy.

Update cue

Small reliability or security patch means quality update. New Windows release or capability level means feature update.

Mobile cue

One bad app gets app repair. Whole-device behavior gets OS, storage, battery, network, or management checks.

Procedure cue

If the question says production change, think rollback, test, scope, risk, approval, and user acceptance.

WORKFLOW 1 — RAW EXPORT AND CONTROL RULES
Organization: Luma Grove Beauty. Role: Alex Morgan, regional director.
Purpose: build a repeatable monthly business-review workbook from raw rows.
Units: Actual, Plan, and PriorYear are net sales in USD thousands; Units is a count.
PriorYear means the same market/channel and same month one year earlier, not last month.
Grain: one row per RecordID; each ID identifies one period/market/channel result.
Preserve the original rows in Raw. An exactly repeated RecordID with identical values is a duplicate export row: retain one copy in CleanData and log the excluded copy. Conflicting values for the same RecordID require clarification; never choose one silently.
Only the periods and market/channel combinations below are in scope. No margin, promotion, inventory, customer, or causal data is supplied.

Workbook design: Raw (unchanged input), CleanData (validated table named ReviewData), Summary (period and market totals), Checks (row reconciliation, missing fields, duplicates, zero denominators).
Calculated columns: Variance = Actual - Plan; VariancePct = (Actual - Plan) / Plan; YoYPct = (Actual - PriorYear) / PriorYear.
Use ratios of totals for summary percentages, never an average of row percentages. If a denominator is zero or missing, flag the metric as unavailable; do not turn it into zero.

    Copilot tips & tricksUseful habits and exercise shortcuts.

    Quick reference
    Ask clarifying questions before Copilot answers▼

    Add “Ask any clarifying questions before responding.” when the answer depends on details you might have left out, such as audience, period, source, format, or the decision at stake. Demo 03 uses it.

    It gives Copilot permission to pause, point out what's unclear, and ask for what it needs instead of silently filling gaps. That can reduce assumptions and rework, but it doesn't replace checking the source or reviewing the final output.

    Ask any clarifying questions before responding.
    A citation is a route to evidence, not a guarantee▼

    Open the source and check the figure, filter, period, and unit. A second AI pass isn't independent verification. Use the reusable verification follow-up in Prompting and safety.

    Four checks before you use any output▼

    Source: did it use the right input? Accuracy: are the important claims supported? Uncertainty: what is unknown? Action: what still needs a person's approval?

    One workflow, one conversation▼

    Start a new conversation for each demo so an earlier source can't leak into the next answer. Demo 06 depends on this to prove the workflow doesn't reuse October's figures.

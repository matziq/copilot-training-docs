WORKFLOW 6 — REUSABLE REVIEW WORKFLOW SPECIFICATION
Organization: Luma Grove Beauty learning case. Role: Alex Morgan, regional director.
Workflow name: monthly-review-check.
Purpose: produce a checked monthly result, not a spending approval or an email.
Required inputs for each run: named source, period, currency/unit, Actual, Plan, PriorYear, and reporting scope.
Rules: verify required inputs before calculations; Actual, Plan, and PriorYear must be numeric; Plan and PriorYear must be nonzero. If a required input is missing or a denominator is zero, ask a clarifying question and stop that run before producing the final brief. Do not fetch a missing value from another period or chat.
Calculations: Variance = Actual - Plan; VariancePct = Variance / Plan; YoYPct = (Actual - PriorYear) / PriorYear. Ratios of totals only.
Output: a headline, calculation table, caveats, and proposed next questions. Facts need source references; suggestions stay labeled proposed.
Never infer profitability, attribution, owners, deadlines, approvals, live refresh, or completed actions.
Never send, share, schedule, or modify other files. Any later workbook editing is a separate, reviewed action in a practice copy.

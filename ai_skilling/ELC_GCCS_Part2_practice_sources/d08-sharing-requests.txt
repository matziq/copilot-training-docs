Agent Builder sharing facts:
- Can edit: owner, with full rights to edit, share, and manage the agent. Can chat: can use the agent only.
- A group can't be an owner. A group can only be a chat user.
- Org-wide sharing for chat access lets everyone in the tenant find the agent in the Agent Store. Admins can limit or turn off org-wide sharing.
- Only the files and folders added to the agent can be shared automatically. Access to a full SharePoint site isn't automatic.
- If sharing a file or folder fails, the agent is still shared. The owner asks the file owner or SharePoint site admin to grant access.
- People can use a shared agent only if they have the license its capabilities require.
- Maintenance: Taylor reviews the library monthly, on the first business day.

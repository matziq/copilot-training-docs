    Demo 01

    Choose the right tool for an operations taskMatch repeated work to a skill, questions to an agent, and decisions to people.

    Core · Tool choice
    A. Practice input▼

    Open Microsoft 365 Copilot, start a new chat, click Copy below, paste, and send. Wait for the short acknowledgment before using B.

    Expected acknowledgment: After you paste this practice data, Copilot should reply only with the acknowledgment line at its end.

    Practice data
    Open TXT
    Practice data: Inspire Brands support-center request backlog
Audience: Copilot Champions supporting site coordinators and operations managers.
Definitions: A prompt is for a one-time task. A skill is saved instructions for a repeatable task. An agent answers questions from its configured instructions and knowledge. People retain approvals and decisions.
R1: Each week, turn the current R101-R104 packaging plan into a short exception brief.
R2: Summarize the current packaging pilot at sites P201-P204 for a manager review.
R3: Give support-center coworkers one place to ask questions about the promotional-material request checklist and current operations practice data.
R4: Approve request M301.
R5: Send the weekly brief to site coordinators.
R6: Turn a recurring four-slide pilot review storyboard into a reusable task.
R7: Each week, calculate site-level packaging variances and flag results at the stated threshold.
Task: classify each request as a one-time prompt, reusable skill, knowledge agent, or human decision/action. Use only these details. Don't invent how often R2, R3, R4, R5, or R6 occurs.
After you receive this source, reply only: "Got it. I'll use this as the source."
    B. Starting prompt (GCSE)▼
    Goal, Context, Source, Expectation
    What this prompt doesSorts the support-center requests into one-time prompts, repeatable skills, knowledge agents, and decisions that require a person.
    Classify the backlog
    <strong>Goal:</strong> Classify each request in the practice backlog.<br><strong>Context:</strong> I am an Inspire Brands Copilot Champion helping operations coworkers choose an appropriate tool.<br><strong>Source:</strong> Use only the practice backlog I pasted.<br><strong>Expectation:</strong> Return a table with request ID, best fit, reason, and any human action required. Do not invent frequency or approve, send, or order anything.
    C. Follow-ups▼

    Copy and send one follow-up at a time in the same chat, agent test, or selected skill. A result stays a draft until a person reviews it.

    Follow-up 1
    Which request is the best first skill candidate, and what input must a user provide each time?
    Follow-up 2
    Which request needs an agent with approved knowledge rather than a reusable document-formatting skill?
    Follow-up 3
    Which requests remain human decisions or actions, and why?
    D. What to check▼
    • R1, R6, and R7 are repeatable workflows; a skill can help after its input and rule are reviewed.
    • R3 is a knowledge question, so a carefully grounded agent fits better than storing current records in a skill.
    • R4 approval and R5 sending stay with authorized people. Do not claim a prompt or skill performed either action.
    • Do not infer frequency for requests where the packet does not state it.
    E. Champion tip▼
    For a peer demo, ask coworkers to classify one familiar recurring task. They often choose an agent for a one-time task; ask whether the job is repeatable and whether it needs its own knowledge source.
    F. Did you know?▼

    A reusable skill is not a shared agent. A skill stores a repeatable workflow; an agent has its own instructions and knowledge sources. Microsoft Support: Create and edit skills · Microsoft Learn: Build agents

    G. Recommended custom instruction▼

    Use only if custom instructions are available to you and allowed by your organization.

    When I describe a task I repeat, help me decide whether a prompt, skill, or agent fits, and explain why.

    Build an operations agent in Agent BuilderDescribe one personal agent, then check what Agent Builder filled in.

    Core · Agent Builder
    A. Practice input▼
    1. In a browser, open m365.cloud.microsoft and sign in with your Inspire Brands work account.
    2. Select Agents & Skills > New agent. Depending on rollout, the labels may be Agents and Create agent.
    3. Choose Describe. Click the box labeled Message Agent Builder, click Copy below, paste with Ctrl+V / Cmd+V, and select Send.
    4. Wait for the fields to fill. Keep the same tab open through Demo 04.

    This is an agent setup request, not a chat-only draft.

    Practice data
    Open TXT
    Build a personal operations knowledge agent named Inspire Ops Library Guide.
Description: Helps Inspire Brands support-center Champions find and explain supplied operations practice data. Cite the uploaded knowledge file and identify the section used.
Instructions:
- Answer only from knowledge I add in Agent Builder. Cite d03-operations-practice-knowledge.txt and name the section that supports each material fact.
- Distinguish current weekly status, the packaging pilot, the promotional-material request checklist, and the packaging-plan review.
- Preserve site IDs, role names, statuses, quantities, thresholds, and dates exactly. Say "Not supplied" when information is missing; never invent dates, approval, completion, owners, recipients, or results.
- Treat the promotional-material request checklist as a draft, not an approved policy. M301 is ready for review, not approved; M302 is incomplete because its needed-by date is not supplied.
- Do not approve requests, decisions, or a rollout; do not send messages, place orders, or claim an attachment exists.
- Do not request or reveal guest or employee personal data. Use role names only.
- Keep answers brief, professional, and in US English. If the knowledge file doesn't support an answer, say so and refer the user to the operations support lead.
Starter prompts:
- Which weekly operations actions remain open at R101 and R102?
- What supplier confirmation is still pending in the packaging pilot?
- Is request M302 ready to route? What information is missing?
    B. Review the Configure fields▼

    Open Configure. Confirm the name is Inspire Ops Library Guide, the description and instructions reflect the setup text in A, and the starter prompts are present. Leave Knowledge empty for D03. Do not add a sharing setting or external action.

    • The one agent continues through knowledge upload and testing in D03-D04.
    • Do not add a SharePoint connection or imply that an operations library is live.
    • For this guide, name limit is 30 characters, description 1,000, instructions 8,000; check the current field guidance in the app.
    C. Champion tip▼
    Show how to open Agents & Skills before pasting. Champions often paste the setup text into regular chat instead of the Agent Builder box labeled Message Agent Builder.
    D. Did you know?▼

    Describe can populate the configuration fields; review them in Configure before testing. Microsoft Learn: Build agents in Agent Builder

    Before you use skills in OfficeCheck access once before Demo 05.

    Office prerequisites
    • License and access: this class assumes the Microsoft 365 Copilot paid add-on for everyone. Copilot and skills must also be enabled by your organization. If a Copilot button is missing in Word, PowerPoint, or Excel, tell the instructor and follow along.
    • Sign in: use your Inspire Brands work account in Word, PowerPoint, and Excel; check the profile name at the top right.
    • Updated desktop apps: use Microsoft 365 desktop apps for Windows or Mac. On Windows, choose File > Account > Update Options > Update Now. On Mac, use Help > Check for Updates. If your organization manages updates, ask IT. Skill menus may be missing or different in web apps; PowerPoint's skills support page lists Windows, Mac, and iPad.
    • Work OneDrive: confirm your work OneDrive opens. Save practice files with File > Save As > OneDrive. Keep AutoSave On when available; it is recommended for reliable Copilot editing, not a strict requirement. Custom skills are saved in a Skills folder in OneDrive.
    • Rollout varies: labels may say skills, plugins, or plugins and skills. The Word-specific labels here were observed in the desktop app; the general Microsoft article doesn't document those exact Word labels.
    • Create once: Demo 05 creates site-readiness-brief (lowercase letters, numbers, and hyphens; up to 64 characters). The description can contain up to 1,024 characters. Don't create duplicates; choose Refresh if it doesn't appear.
    • On/off differences: a skill turned off in PowerPoint Manage skills is hidden from the menu. In Excel, a turned-off skill can still be selected by typing its @ name. For these demos, leave the skill on and select it from the menu.
    • Protect data: don't put confidential information, guest or employee personal data, passwords, or secrets in a skill. Use only this guide's practice data.

    What you need to know

    Open a blank file, click the guide's Copy button, paste with Ctrl+V (Windows) or Cmd+V (Mac), click Home > Copilot, and save to OneDrive. A pane is the panel beside the document. Each demo lists where to click next.

    Demo 05

    Create and save the reusable skill in WordEnter three separate fields; confirm the saved skill appears before moving on.

    Core · Word · Skills
    A. Word setup and skill fields▼

    First check Before you use skills in Office. Create the skill directly in Word; no chat rewrite is needed.

    1. Open Word desktop and choose Blank document.
    2. Choose File > Save As > OneDrive. Name it Inspire site readiness practice and select Save. Keep it open for D06.
    3. Select Home > Copilot > More options (...) > Manage plugins > Custom skills.
    4. If site-readiness-brief already appears, don't create it again. Go to B and confirm it's available.
    5. If the page is empty and offers Create to initialize the Skills folder, choose it once. Then select Create > Create manually.

    Copy each field separately, return to Word, click its matching field, and paste with Ctrl+V / Cmd+V. Don't paste the complete file into one box.

    Name
    site-readiness-brief
    Description
    Draft or update a site readiness brief, packaging-pilot storyboard, or packaging variance review from the active Word document, PowerPoint presentation, or Excel workbook.
    Instructions
    Use only the active file and its supplied practice data. Keep site IDs, roles, statuses, quantities, thresholds, and dates exactly as shown. If a needed date, status, owner, or approval is missing, say "Not supplied" or ask; never invent it. Do not copy any source acknowledgment line into an output. Do not request or include guest or employee personal data.

Word: create or update a concise draft with Overview, Exceptions, Next actions, and Missing information. Preserve the document title and unrelated content. Do not call a draft an approval.

PowerPoint: for a packaging pilot review, make four slides titled Purpose and scope, Readiness snapshot, Open dependencies, and Discussion and next actions. Use one headline and no more than three bullets per slide. Add source site IDs in speaker notes. Preserve pending statuses and the existing theme. Do not add sales, savings, ROI, launch-date, or approval claims.

Excel: keep the original input sheet unchanged. Add a Review sheet with Site, Planned units, Actual units, Variance units, Variance %, and Flag. Calculate Variance units as actual minus planned; Variance % as variance divided by planned. Flag Review when the absolute percentage is at least 10%; otherwise flag OK. If planned is zero, show Not calculable and Review instead of dividing by zero. Calculate total percentage from total variance divided by total planned, not the average of site percentages. Use formulas where available; display percentages to one decimal place.

After editing, check each result against the active file, preserve missing information, and briefly tell the user what changed. This skill drafts and analyzes only; never approve, send, order, or publish.

    Open optional complete skill TXT (the Add form uses the three separate boxes above).

    Use the three Copy buttons above for the matching form fields, not the optional full file.

    Champion playbookA repeatable approach for peer support.

    For Champions

    Run a 10-minute peer demo

    1. Ask a coworker to choose a repeatable, low-risk task (2 minutes).
    2. Show the source data and identify anything missing (2 minutes).
    3. Demonstrate one prompt, skill, or personal agent (3 minutes).
    4. Open the edited file or citation and verify the result together (2 minutes).
    5. Close with one safety boundary and a next step (1 minute).

    Collect team use cases

    Ask coworkers: What task repeats? Which inputs are allowed? What should the output look like? Which decisions must remain with a person? Record role-level examples only; don't collect guest or employee personal information in a practice skill.

    Route access issues to IT

    Send license, rollout, and missing-menu questions to IT or the Microsoft 365 administrator. Include the app, desktop/web, work account, approximate time, and exact menu label; don't send confidential source data.

    Keep ownership clear

    Keep practice agents personal. Before any team use, identify a team owner, make an explicit sharing decision, confirm permissions, and review test results. A demo is not authorization to deploy or share.

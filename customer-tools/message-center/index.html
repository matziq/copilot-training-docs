The Microsoft Copilot app Home experience brings together Chat, Cowork, Projects, and Workspaces. Worldwide standard release begins in late October 2026; deferred release begins in late November 2026.

MC1509801 — Microsoft Teams: Customize file extensions blocked by Weaponizable File Protection2026-11-02

Microsoft Teamsadminsmedium

Teams will let admins customize file extensions blocked by Weaponizable File Protection or retain the Microsoft-recommended list. The November 2 update moves worldwide general availability to early through mid-December 2026.

User impact: Blocked files remain blocked as today. Organizations using the recommended list continue receiving automatic updates; customized lists no longer receive those updates.
Admin action: No action is required to retain the default list. If customization is needed, review the security implications and add or remove extensions. Reset to the Microsoft-recommended list at any time to resume automatic updates.
